# 면접 질문 생성 데이터 흐름

작성 기준: 2026-06-18

## 현재 흐름

```text
InterviewSession
-> user, jd, resume, cover_letter 조회
-> resume.github_url 포함
-> user.projects 기반 ProjectExperience 목록 포함 가능
-> AI/question bank 질문 생성
```

## GitHub URL 출처 표기 목표

분석 대상 URL은 문자열로 합치지 않고 출처를 분리한다.

```json
{
  "source_type": "project_experience",
  "project_experience_id": "uuid",
  "project_name": "Career.zip",
  "github_url": "https://github.com/example/career-zip"
}
```

```json
{
  "source_type": "resume",
  "resume_id": "uuid",
  "github_url": "https://github.com/example/career-zip"
}
```

```json
{
  "source_type": "user_profile",
  "github_url": "https://github.com/example"
}
```

## 승인 필요

현재는 선택 이력서와 프로젝트 경험의 직접 매핑이 없어 “선택한 이력서에 연결된 프로젝트만 조회”를 보장할 수 없다. FK 또는 mapping 테이블 설계 승인 후 질문 생성 파이프라인에 `project_experience_id` 목록을 명시 전달해야 한다.
