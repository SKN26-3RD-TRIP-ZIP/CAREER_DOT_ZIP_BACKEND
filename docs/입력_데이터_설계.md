# 입력 데이터 설계

작성 기준: 2026-06-18

## GitHub URL 저장 규칙

```text
사용자 대표 GitHub = input_userprofile.github_url
이력서 대표/참고 GitHub = input_resumemaster.github_url
프로젝트 Repository = input_projectexperience.github_url
```

`ProjectExperience` row 하나에는 Repository URL 하나만 저장한다. URL이 없는 프로젝트도 저장할 수 있으며 빈 값을 사용자 프로필 GitHub URL로 대체하지 않는다.

## 현재 모델 관계

```text
UserProfile -> User OneToOne
ResumeMaster -> User FK
ProjectExperience -> User FK
CoverLetter -> User FK, JobDescription FK nullable
InterviewSession -> User FK, JobDescription FK, ResumeMaster FK nullable, CoverLetter FK nullable
```

`ProjectExperience -> ResumeMaster` 직접 관계는 없다. 복수 이력서별 프로젝트 포함 여부는 현재 DB 구조만으로 구분할 수 없다.
